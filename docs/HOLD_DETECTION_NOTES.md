# 岩点识别:当前假设与未来优化

本文件记录当前 `hold_detect.py` / `detect_purple_a.py` 里**硬编码**的参数和假设,
便于日后替换为更鲁棒的做法。

## 当前假设(2026-10-13)

### A. 路线颜色先验
- **假设**:整条路线上绝大多数岩点都是**紫色**。
- **影响**:单色过滤后,识别从"多色分类 + 事后 touched 过滤"退化为"二值分割",
  排除掉大部分假阳性(地垫、警示角、其他颜色的大岩点)。
- **目前实现**:固定 Hue 区间 `[110, 148]`(OpenCV HSV scale 0-180)。
  区间宽,保证蓝紫+深紫+品红变种都被收;精度由多重后置过滤器把关。

### B. HSV / 几何阈值
| 参数 | 值 | 作用 |
|---|---|---|
| Hue | [110, 148] | 宽泛,覆盖紫色所有子色 |
| Saturation 下界 | 25 | 允许暗哑的塑料岩点 |
| Value 下界 | 35 | 允许暗紫岩点 |
| area 最小 | 0.012% 画面 | 允许小脚点 |
| area 最大 | 5% 画面 | 允许大 volume |
| bbox 长宽比上限 | 3.0 | 排除边界细条 |
| merge radius | 1.5% 画面高 | 密集区岩点别被合并 |

### C. 参考帧选取
| 参数 | 值 | 作用 |
|---|---|---|
| 攀爬段 16 帧 | y-quantile 跨整个 climb | 每块墙都轮到一帧 climber 不在那 |
| **攀爬前 5 帧**(climber 未进入) | 均匀采样 | 无 climber,纯墙视图,最佳信号 |

### D. 多重精度过滤器(按顺序应用)
| 过滤器 | 阈值 | 作用 |
|---|---|---|
| 边缘裁剪 | x,y 在画面 2.5% 边缘内丢 | 天花板、画框黑边 |
| support(跨帧出现次数) | ≥ 2/21 | 过滤单帧偶发 |
| V std(blob 内亮度方差) | ≥ 10 | **真 3D 岩点有光影,平墙均匀** |
| 核心紫色占比 | 中心 5×5 patch ≥ 65% | **实心紫岩点有核心,边界伪影没有** |
| 环采样紫色占比 | 环内 ≤ 45% | 排除嵌入大紫色区域的碎片 |

### E. 单路线假设
- 画面中出现的紫岩点都当成目标线路成员。
- **未处理**:如果墙上还有另一条紫色路线,会被一起收进来。

## 日后要优化的点(优先级从高到低)

### 1. Hue 自学习(替代硬编码紫色区间)
- 从一张"攀爬者正在起始岩点"的参考帧,采样 climber 手/脚**最近邻 blob 的像素**。
- 取其 Hue 中位数 ± 一倍 MAD 作为自适应 Hue 窗口。
- 好处:不同场馆/光线下不用改代码;对洋红、茄紫、梅红等变种更鲁棒。

### 2. 墙面 ROI
- 自动估:取第 1 帧墙面的**主色块多边形**(大面积连通区域,排除地面/天花板)。
- 或人工:在视频头让用户点 4 个点。
- 任何 blob 中心必须落在 ROI 内。

### 3. 多路线情况
- 场馆通常用**颜色标签胶带**在岩点旁边作标记,而不是岩点本身颜色。
- 以后要适配胶带:在每个候选 blob 外侧 20px 环形内找同色小 blob,确认它是路线成员。
- 或要求用户在视频开头演示"抓一下起始岩点",从空间近邻学路线成员。

### 4. 底色与岩点同色时的鲁棒检测
- 当前完全丢弃黑/低饱和岩点。
- 可叠加 Canny 边缘 + 封闭轮廓的面积滤波作为备选信号。
- 或用预训练岩点检测器(CruxVision 的 YOLOv8 权重)。

### 5. 跨帧合并
- 现在只按坐标距离合并,大岩点被切成多瓣时可能合不回来。
- 改成**凸包 + IoU** 合并:两瓣如果凸包有 IoU > 0.3,合并为一个。

### 6. 碎片 vs 独立岩点的区分
- 密集区域(墙拐角处)多个岩点彼此距离 < merge_radius,会被错误合并,或反之碎片未合并。
- 需要形态学 + 色彩方差辅助:若"合并后方差 > 阈值",则拆回;若"碎片间色相差 < 5",则合并。
